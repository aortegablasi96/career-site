# Project: NumisBook

Used Claude Code to fully develop a SaaS coin collection management solution with an AI-assited chatbot. 

- Orchestrated workflow, execution, governance and management Claude Skills to simulate a team in charge of the entire development pipeline.
- Includes an AI to support the management of the collection and automate processes such as adding a new coin into the collection.
- Deployed in Vercel, Neon and CloudFlare.

To review how I did it, check the github repository: https://github.com/aortegablasi96/numisbook
