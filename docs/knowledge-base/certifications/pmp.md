# Certification: Project Management Professional (PMP)

**Institution:** Project Management Institution (PMI)  
**Date of emission:** June 2024

**Badge: https://www.credly.com/badges/0453ee02-59fe-441b-9481-48ca4030662d**

**Description:** It covers the foundations of project management and its methodologies (Waterfall, Agile, Hybrid). It describes how the project manager can handle the project management stages (Project initiation, project plannification, project execution, monitorization and control of project exeuction's, project closure) and the different factors associated to it, such as stakeholders management.
