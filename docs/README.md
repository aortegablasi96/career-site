# docs/

The project's durable documentation. The work itself and its history live in GitHub issues and
pull requests.

| Path                                                 | What it holds                                                    |
| ---------------------------------------------------- | ---------------------------------------------------------------- |
| [`decisions/`](decisions/README.md)                  | ADRs (architecture) and DDRs (UI and UX), with their templates and the next free numbers |
| [`implementation-notes.md`](implementation-notes.md) | The traps that the tests and the records don't make obvious, and how to check a change in a browser |
| `knowledge-base/`                                    | The owner's source material for the site's content: profile, experiences, studies, certifications, skills and portfolio |

* **Before relying on a decision record or writing one**, read
  [`decisions/README.md`](decisions/README.md). It maps which records supersede or amend which.
* **Before changing styles, print, the contents bar, the timelines, the introduction, fonts or
  assets**, read the implementation notes.
* **The knowledge base is a source, not a page.** `content/` draws from it only the facts a story
  names.
